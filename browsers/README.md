# Browsers

Vivaldi configs — nije upravljano kroz Home Manager, sve se kopira ručno.

## css/
`titlebar.css` — custom CSS za Vivaldi. Kopirati u Vivaldi devtools ili custom CSS polje u postavkama.

## extensions/
`vimium-options.json` — Vimium konfiguracija. Importati kroz Vimium Options → Restore.

## shortcuts/
Vivaldi keyboard shortcuts. Kopirati sadržaj u `~/.config/vivaldi/Default/Preferences` (zamijeniti postojeći shortcuts key).

## themes/
`settings.json` — Vivaldi tema. Napraviti `.zip` i importati kroz Vivaldi Themes postavke.
